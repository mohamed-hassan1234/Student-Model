# Dataset Governance

Dataset candidates may use only approved sources, permitted licenses, allowed retrieval use, allowed training use, permitted teacher output, and recorded provenance.

Records are excluded when source license status is unresolved, training permission is missing, teacher-output training permission is missing, source is blocked, human review is missing, risk is unresolved, or the record belongs to an evaluation set.

Generated datasets are local artifacts under ignored storage and must not be committed.
