# Teacher-Provider Policy

The Phase 2 teacher interface supports local open-weight models, approved internal models, deterministic tools, human-authored answers, and optional external providers after explicit approval.

The implemented provider is the deterministic mock teacher. It requires no paid API, no internet inference, no closed chat product, and no model download.

External providers remain disabled by default and require a usage-policy decision, training-use permission decision, provider identity, model identity, request purpose, and secret redaction.
