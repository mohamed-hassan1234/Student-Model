# Curriculum Architecture

The Phase 2 curriculum is represented in MongoDB through `curricula` and `curriculum_topics`.

Each topic records domain, topic, subtopic, learning objective, prerequisites, difficulty, importance, source counts, document counts, verified-question counts, evaluation-example counts, coverage score, quality score, known gaps, and the next recommended action.

Initial Technology Student domains are Web Fundamentals, Frontend, Backend, Database, Development Tools, and Software Engineering. Coverage is evidence-driven and must not claim completeness when approved sources, ingested documents, verified questions, or evaluation examples are missing.
