# Question-Generation Methodology

Question generation is bounded by `LEARNING_CYCLE_MAX_EXAMPLES` and learning-cycle limits.

Phase 2 uses deterministic templates for definition, explanation, comparison, examples, tasks, debugging, code generation, code completion, review, security review, architecture, scenario, misconception, unsupported-question, source-conflict, practical-project, and multiple-solution categories.

Every generated question records provider identity, model identity, source basis, configuration, content hash, duplicate status, and review status.
