# Base Model Policy

Base models require a manifest with model identifier, exact revision, tokenizer revision, architecture, context length, license, fine-tuning permission, redistribution status, trust-remote-code requirement, expected resources, hashes where available, license review, and approval status.

Training refuses unresolved licenses, missing pinned revisions, unresolved fine-tuning permission, unapproved manifests, and unapproved remote code. Large model downloads are never automatic.
