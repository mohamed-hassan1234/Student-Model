# Dataset Entry Gate

Phase 3 accepts only immutable approved dataset versions from Phase 2. Records must preserve source provenance, source license, retrieval permission, training permission, teacher provenance, teacher-output training permission, verification scores, human approval, content hash, leakage check, and evaluation exclusion.

The gate rejects pending, rejected, unlicensed, unknown-provenance, evaluation, blocked-source, secret-containing, duplicate-risk, or high-risk unresolved records. Validation reports include split counts, distributions, length statistics, token estimates, duplicate statistics, leakage statistics, and blocking issues.
